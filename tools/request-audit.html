Request & Firebase Audit

Đọc HAR từ DevTools để xem request trình duyệt gửi đi và tìm dấu hiệu ghi dữ liệu Firebase.

Chạy hoàn toàn trong trình duyệt
Giới hạn quan trọng: HAR chỉ ghi request của trình duyệt. Nếu frontend gọi Worker rồi Worker gọi Firestore nội bộ, HAR chỉ hiện request tới Worker; muốn xác nhận lệnh nội bộ cần kiểm tra Worker source/logs.
1. Ghi request của ứng dụng

Mở ứng dụng trong tab khác → nhấn F12 → Network → bật Preserve log → tải lại trang và thao tác các tính năng cần kiểm tra.

2. Xuất HAR rồi mở ở đây

Trong Network, nhấp phải danh sách request → Save all as HAR with content. Chọn file đó ở vùng bên dưới. Không cần upload file lên server.
